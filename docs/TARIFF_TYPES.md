# Типы тарифов

Утверждённый справочник: `hour`, `shift`, `day`, `month`, `trip`, `km`.

`machinery_categories.code` — внутреннее обозначение **типа транспорта**, не прав. Тип лицензии — обязательная ссылка на справочник `license_types` у той же строки.

Исполнитель не выбирает тариф из полного списка мира: только из типов, разрешённых **категории** его транспорта. Связь хранится в таблице `category_pricing_types`.

## Справочник `pricing_types`

| code    | Название |
| ------- | -------- |
| `hour`  | Час      |
| `shift` | Смена    |
| `day`   | Сутки    |
| `month` | Месяц    |
| `trip`  | Рейс     |
| `km`    | Километр |

`week` и `callout` в справочник не входят.

## Зачем связь с категорией

`trip` и `km` — это тариф **на перемещение груза/машины** (эвакуация, рейс самосвала).  
Кран, экскаватор, погрузчик работают **на точке**: их считают часом, сменой, сутками, месяцем. Рейс для крана как единица работы не используется.

В рыночных прайсах у автокрана иногда есть «₽/км за МКАД». Это надбавка за доставку на объект. В каталог тарифов не выносим: заказчик задаёт количество по выбранному тарифу, сумма = ставка × количество.

## Группы категорий

| Группа    | Смысл                 | Разрешённые тарифы                            |
| --------- | --------------------- | --------------------------------------------- |
| `on_site` | Работа на объекте     | `hour`, `shift`, `day`, `month`               |
| `haulage` | Перевозка / эвакуация | `hour`, `shift`, `day`, `month`, `trip`, `km` |
| `mixed`   | И на точке, и рейсом  | `hour`, `shift`, `day`, `month`, `trip`, `km` |

## Пример состава категорий и связи

Источник истины — строки в `category_pricing_types`, не хардкод в клиенте. Категории создаёт админ в админке (сида нет). Ниже — пример, какие тарифы обычно ставят типу.

| category.code     | Название    | Группа  | hour | shift | day | month | trip | km  |
| ----------------- | ----------- | ------- | ---- | ----- | --- | ----- | ---- | --- |
| `tow_truck`       | Эвакуатор   | haulage | да   | да    | да  | да    | да   | да  |
| `dump_truck`      | Самосвал    | haulage | да   | да    | да  | да    | да   | да  |
| `manipulator`     | Манипулятор | mixed   | да   | да    | да  | да    | да   | да  |
| `crane`           | Кран        | on_site | да   | да    | да  | да    | нет  | нет |
| `excavator`       | Экскаватор  | on_site | да   | да    | да  | да    | нет  | нет |
| `loader`          | Погрузчик   | on_site | да   | да    | да  | да    | нет  | нет |
| `bulldozer`       | Бульдозер   | on_site | да   | да    | да  | да    | нет  | нет |
| `aerial_platform` | Автовышка   | on_site | да   | да    | да  | да    | нет  | нет |

Новая категория — в админке: `code`, `name_ru`, обязательный тип лицензии из `license_types`, `is_active` + набор разрешённых тарифов в `category_pricing_types`. JSON-конфига лицензий нет.

## Правила для исполнителя

- После выбора типа транспорта UI показывает только разрешённые тарифы.
- Нужно указать хотя бы один тариф из разрешённых.
- Нельзя сохранить `pricing_type`, которого нет в связи с категорией (`400 PRICING_TYPE_NOT_ALLOWED_FOR_CATEGORY`).
- Не обязательно заполнять все разрешённые типы.
