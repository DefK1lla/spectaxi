# 14 — Выбор стратегии шаринга web ↔ mobile

**Важность:** высокая. Пока клиент пишем только в `apps/mobile`; без этого решения нельзя красиво и осознанно выносить общий продукт в `packages/` / Solito / logic-only.

## Зачем

Нужно решить, **как** делить общее между Next (`web`) и Expo (`mobile`): жирный `packages/app`, `ui`+`screens`, только logic, T3-стиль и т.д. От выбора зависят FSD-слои, зависимости и момент выноса кода из mobile.
