# SpexTaxi

Мобильный маркетплейс спецтехники: эвакуатор, кран, экскаватор и другой транспорт. Один аккаунт — клиент и/или исполнитель. Вход по телефону.

В репозитории пока только продуктовые документы MVP, кода приложения нет.

Клиент ищет машину в списке и на карте, отправляет запрос одному исполнителю, после принятия открываются контакты и переговоры. Цену указывает заказчик; при безопасной сделке сначала холд, потом работа. Спор и апелляция закрывает админ. Прямая оплата вне приложения тоже допустима.
